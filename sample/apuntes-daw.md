# Apuntes de Desarrollo de Aplicaciones Web (DAW)

## ¿Qué es el ciclo DAW?

El Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Web (DAW) pertenece a la
familia profesional de Informática y Comunicaciones. Tiene una duración de 2000 horas
distribuidas en dos cursos académicos, e incluye un módulo de Formación en Centros de
Trabajo (FCT) de 400 horas que se realiza en el segundo curso.

Al terminar se obtiene el título de Técnico Superior en Desarrollo de Aplicaciones Web, que
tiene nivel 5 en el Marco Español de Cualificaciones y permite acceder a estudios
universitarios de grado.

## Módulos principales

En el primer curso se cursan Programación, Bases de Datos, Entornos de Desarrollo, Lenguajes
de Marcas, Sistemas Informáticos y Formación y Orientación Laboral. En el segundo curso se
estudian Desarrollo Web en Entorno Cliente, Desarrollo Web en Entorno Servidor, Despliegue
de Aplicaciones Web, Diseño de Interfaces Web, Empresa e Iniciativa Emprendedora y el
proyecto final.

La programación se imparte con Java, mientras que el desarrollo web en entorno servidor
utiliza PHP y el entorno cliente se trabaja con JavaScript moderno.

## Salidas profesionales

Las salidas profesionales más habituales son desarrollador web, desarrollador front-end,
desarrollador back-end, desarrollador full stack, técnico de bases de datos y consultor de
aplicaciones web. El salario de entrada de un perfil junior en España se sitúa entre 20.000
y 30.000 euros brutos anuales, según la Guía Salarial 2026.

## Tecnologías más demandadas en 2026

Los perfiles con mayor demanda combinan una base sólida de desarrollo web con una
especialización. Las empresas piden sobre todo TypeScript, React y Node.js en el stack
JavaScript, y Python con FastAPI o Django en back-end. PHP y Laravel siguen teniendo mucha
presencia en pymes y agencias digitales.

La integración de inteligencia artificial es el factor diferencial con mayor impacto
salarial: saber integrar APIs de modelos de lenguaje, construir sistemas RAG y automatizar
tareas con agentes puede incrementar el salario base hasta un 56 por ciento.

También se valoran Docker, Git, pruebas automatizadas, SQL y conocimientos de accesibilidad
y rendimiento web.

## Buenas prácticas de desarrollo

El control de versiones con Git es imprescindible: se recomienda trabajar con ramas cortas,
mensajes de commit descriptivos y revisiones de código mediante pull requests.

En seguridad, toda consulta a base de datos debe usar sentencias preparadas para evitar
inyección SQL, las contraseñas deben almacenarse con funciones de hash como bcrypt o Argon2
y nunca en texto plano, y los formularios deben protegerse con tokens CSRF.

En accesibilidad, las páginas deben usar HTML semántico, etiquetas ARIA solo cuando sea
necesario, contraste suficiente y navegación completa por teclado.

## Cómo preparar una entrevista técnica

Conviene practicar explicando en voz alta un proyecto propio: qué problema resolvía, qué
decisiones técnicas se tomaron y por qué, qué partes fueron más difíciles y qué se
mejoraría. Los entrevistadores valoran más la capacidad de razonar y comunicar que memorizar
sintaxis.
